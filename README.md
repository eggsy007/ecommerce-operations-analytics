# E-commerce Operations & Customer Analytics

## Overview
End-to-end analytics project on 99K+ orders from Olist, 
a Brazilian e-commerce marketplace. Built using PostgreSQL 
and Power BI to analyze order funnel, delivery SLA, 
customer cohorts, and RFM segmentation.

## Tools & Technologies
- PostgreSQL (pgAdmin)
- Power BI Desktop
- Microsoft Excel (EDA)

## Key Findings
1. Dispatch stage is the biggest funnel drop-off — 
   1,537 orders approved but never shipped
2. Northeast Brazil has highest late delivery rates — 
   AL state at 23.93%
3. Monthly retention is <1% across all cohorts — 
   one-time purchase platform behavior
4. At Risk segment is 23.45% of customer base with 
   avg spend of $241 — highest re-engagement priority

## Dashboard Pages
- **Page 1 — Operations Overview:** Funnel, SLA,

- **Page 2 — Customer Intelligence:** RFM segments,
